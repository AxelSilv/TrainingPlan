# Mistä löydän Connection Stringin Neonissa?

## Vaihe 1: Mene Settings-välilehdelle

1. Neon Dashboardissa (missä olet nyt)
2. Vasemmalla puolella on **"PROJECT"** -osio
3. Klikkaa **"Settings"** (hammasratas-ikoni)
4. Siellä pitäisi olla **"Connection Details"** -osio

## Vaihtoehto 2: SQL Editor

1. Vasemmalla klikkaa **"SQL Editor"** (koodi-ikoni)
2. Yläosassa voi olla **"Connection String"** -linkki tai -nappi
3. Tai **"Connection Details"** -nappi

## Vaihtoehto 3: Connect-nappi

1. Yläoikealla on **"Connect"** -nappi (ketju-ikoni)
2. Klikkaa sitä
3. Siellä näkyy Connection String

## Jos et löydä sitä:

Voimme käyttää SQL Editoria suoraan seedin ajamiseen. Tämä vaatii seed.ts:n muuntamisen SQL:ksi, mutta se on mahdollista.

**Kokeile ensin:** Klikkaa yläoikealla olevaa **"Connect"** -nappia - siellä pitäisi olla Connection String!
